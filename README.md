# 星途 · 自闭症全周期成长陪伴服务系统

> 高阶创新创业课程 · 创新服务设计 结课大作业

## 项目简介

"星途"是一套面向自闭症谱系障碍（ASD）儿童及青少年的全周期成长陪伴服务系统，覆盖0-18岁四个发展阶段，针对男女不同性别差异设计系列化产品与服务。

核心定位：**分龄、分性别、分场景** —— 通过硬件教具、线上平台和专业顾问网络三位一体的服务模式，解决自闭症家庭在不同成长阶段面临的干预资源不足、专业指导匮乏、家长焦虑无处释放等痛点。
